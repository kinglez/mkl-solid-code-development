Contributing
------------
Keep changes focused, preserve source attribution, and update affected docs.
For validator defects, add a failing regression test before applying the fix.
Run these executable commands from the package root before submitting changes:

    python3 -m unittest discover -s tests -v
    python3 tools/run_all_validators.py
    python3 tools/run_all_validators.py --check-structure

Submit a pull request when a repository remote is available. Explain the
problem, resulting behavior, affected skills, and actual verification results.
AI tools are not coauthors; disclose material AI assistance.
